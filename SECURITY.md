# Security

Security fixes target the latest version. This is an experimental application;
there is no guarantee of support for older versions or untested Mac models.

Use GitHub's private vulnerability reporting feature if it is enabled for the
repository. If it is unavailable, open an issue requesting a private contact
without including vulnerability details, credentials, or screen content.

Include the affected version, reproduction steps, and the practical impact.
For ordinary bugs such as animation artifacts, use the bug-report template.
