# Liduo 0.2.4 — preview

Liduo adds a lid-driven bend, blur, and darkening effect to a MacBook's desktop.
This first public preview includes source code and an ad-hoc-signed Mac application.
It has no Developer ID certificate and has not been notarized by Apple.

## Included

- Three styles: soft bend, deeper shading, and frosted glass.
- Adjustable appearance and cutoff angle, manual preview, and a desktop demonstration.
- Local processing with no accounts, telemetry, audio capture, or saved screen frames.
- Updated sample artwork, cached blur processing, and a fix for missed preview updates after idle.
- A clear hint when the manual preview angle is above the effect cutoff.
- MIT-licensed source code, build instructions, and a GitHub Actions workflow.
- Homebrew and GitHub-based npx installers with SHA-256 verification and app-only launch permission.

## Compatibility

macOS 26+ on an Apple silicon MacBook with a compatible lid-angle sensor.
Tested on MacBook Pro M4 Pro. The interface is in Russian.

## Known limitations

This is an experimental image overlay. The sensor and background pointer handling
have hardware and OS compatibility limits. Battery duration and other MacBook
models have not been fully tested. See `docs/TESTING.md` and `README.md`.

Install instructions are in `docs/INSTALLING.md`; source build instructions are in
`docs/BUILDING.md`. Grant screen access separately in macOS settings. The preview
artwork has separate terms in `ASSETS.md`.
