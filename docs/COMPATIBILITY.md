# Совместимость MacBook

Для реакции на движение крышки нужен датчик, который передает ее угол.
Наличие процессора M-серии само по себе этого не гарантирует. Текущие готовые
сборки Liduo требуют Apple silicon и macOS 26 или новее.

| Семейство | Датчик угла | Проверка Liduo |
| --- | --- | --- |
| MacBook Pro 14″ и 16″ с Apple silicon, начиная с 2021 года | Есть у перечисленных ниже поколений | Локально проверен M4 Pro; остальные требуют проверки |
| MacBook Air M2, M3 и M4, 13″ и 15″ | Есть | Требуется проверка; встречаются недоступные через стандартный HID интерфейсы |
| MacBook Air M1 (2020) | Нет; доступно состояние «открыто/закрыто» | Автоматический эффект по углу невозможен |
| MacBook Pro 13″ с M1 или M2 | Нет датчика угла | Автоматический эффект по углу невозможен |
| MacBook Pro 16″ Intel (2019) | Есть | Текущая готовая сборка arm64 не поддерживает Intel |
| Другие старые Intel MacBook | Наличие датчика не подтверждено; большинство используют выключатель крышки | Не поддерживаются текущей сборкой |
| Новые модели, которых нет в таблице | Определяется при запуске | Не блокируются по списку моделей; нужна проверка на устройстве |

Перечень аппаратуры основан на [данных проекта LidAngleSensor](https://github.com/samhenrigold/LidAngleSensor/issues/36)
и его [проверке моделей](https://github.com/samhenrigold/LidAngleSensor/blob/main/LidAngleSensor/HardwareCompat.swift).
Указанные там MacBook Pro с Apple silicon: M1 Pro/Max, M2 Pro/Max,
M3/M3 Pro/M3 Max и M4/M4 Pro/M4 Max. Наличие датчика не равно подтвержденной
работе Liduo на конкретной модели и версии macOS.

На части [MacBook Air M2](https://github.com/samhenrigold/LidAngleSensor/issues/45)
видны устройства Apple SPU с тем же Product ID, но без интерфейса угла.
Один Product ID не позволяет считать их показания углом крышки. Liduo не
подменяет отсутствующий угол показаниями освещенности или акселерометра.

На Air M1 переустановка приложения и разрешение записи экрана не добавят
датчик. Через SMC доступен [выключатель крышки MSLD](https://github.com/AsahiLinux/docs/blob/main/docs/hw/soc/smc.md)
с двумя состояниями, без промежуточных углов. Ручной предпросмотр и
пятисекундная демонстрация остаются доступны.

## Отчет с другого MacBook

В корне проекта выполните:

```sh
zsh scripts/diagnose-lid.sh
```

Скрипт только читает модель, версию macOS и список устройств Apple HID.
Он не запрашивает пароль, не меняет настройки и не отправляет данные.
К отчету полезно добавить версию Liduo и сообщение из раздела «Диагностика».
Отчет показывает доступность интерфейса; работоспособность чтения и плавность
эффекта проверяются отдельно при движении крышки, после сна и пробуждения.
